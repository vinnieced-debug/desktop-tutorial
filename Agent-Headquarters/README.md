# Agent Headquarters

This folder is the brain. Every agent reads it before it works.
Point Claude (Cowork or Code) at this folder so it starts with full context.

## How it is organized

| Folder | What goes in it |
|---|---|
| 00-start-here | Who I am, my goals, my rules, my voice. Every agent reads this first. |
| 01-open-concept-retail | The boutique. How it runs and how it makes money. |
| 02-book | Lessons of a Serial Entrepreneur. |
| 03-home-and-family | Household logistics, school, calendar. |
| 04-my-ip | My raw material. Voice notes, transcripts, saved ideas. |
| 05-agents | One job description per agent. |
| 06-memory | What the agents learned from my feedback. |
| 07-outputs | Finished work lands here so I can find it. |
| private | My long-term personal plans. Never shared, never used in partner documents. |

## The rules for this folder

1. One business per folder. Agents do not mix businesses.
2. Fill in the brackets [like this]. Delete a prompt once it is answered.
3. Short and true beats long and polished.
4. When something changes, update the file. A stale file makes a wrong agent.
